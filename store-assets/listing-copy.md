# Chrome Web Store Listing Copy

## Name

TabWeave

## Short Description

Rule-driven Chrome tab grouping with Side Panel workspace, Command search, cleanup tools, and optional AI grouping.

## Detailed Description

TabWeave keeps busy Chrome windows organized with dependable rules and a fast workspace for everyday tab cleanup.

Create rules for URL, title, domain, keyword, and regex matches, then let TabWeave group matching tabs automatically as you browse. Open the workspace from the Chrome Side Panel or Popup to review groups, close noisy tabs, create manual groups, and run cleanup actions without leaving the current window.

Highlights:

- Rule-driven tab grouping with drag-to-reorder priority
- Side Panel or Popup workspace for the current window
- Command search for open tabs, groups, history, and built-in actions
- Duplicate tab cleanup, tab hibernation, and snooze-friendly workflows
- Optional AI grouping with provider-specific local API key storage
- Light/dark themes, Chinese/English UI, and Chrome shortcut support

Privacy:

TabWeave is designed to be local-first. Rules and preferences are stored on your device by default. Optional AI features are user-configured, and full URL sharing can be turned off.
